# 組み分けぼうし

## アプリを作った理由

 　懇親会などで、アプリを使用してグループ分けをした際に同じメンバーと被ることがあり、
 話したことのない人とは別グループになってしまった経緯から、一度同じグループになった人とは
 極力被らないアプリを作成しようと思いました。
 　また、以前作成したミニアプリは見た目を極力シンプルにしたので今回は、見た目に力をいれようと思いました。

## できること（機能一覧）

 　メンバーを入力し、組数をしていすると、組み分けを行います。
 　2回目以降は、同じメンバーと被らないように、被り防止機能をONにできます。
